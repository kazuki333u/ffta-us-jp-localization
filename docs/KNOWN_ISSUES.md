現時点で把握している、**プレイヤーから見える**未解決の事項です。
直った項目は [`../CHANGELOG.md`](../CHANGELOG.md) にあります。

同じ内容の報告でも歓迎します。重複を恐れず報告してください。

## 1. 表示 — ミッション条件文の重複表示 (US版と同じ表示)

**症状**
一部のミッションで、必要なアイテムが足りないときの酒場の文に
**同じアイテム名が2回**続けて表示されます (「A と A が必要」のような形)。

**深刻度** 低 (表示のみ。進行に影響する報告はありません)

**状況**
元のゲームの動作と考えています。
このミッションの条件データでは、2つの必要アイテムが同じアイテムになっています。
このパッチは、条件データも名前を差し込む処理も変更していません
(US版とバイト単位で一致することを確認済み。US版の実機での表示はまだ確かめていません)。
パッチ側の不具合ではないため、修正の予定はありません。

## 2. 検証中 — US版追加コンテンツの表示

US版には、日本版に存在しないミッション・シナリオ・派遣報告などがあります。
これらは**すべて本プロジェクトが日本語に翻訳済み**です。
「翻訳が入っていない」のではなく、
「入っている翻訳をゲーム中で見た記録がまだ取れていない」ものが残っています。

**まだ確かめていないこと**

- US版で追加された**終盤ミッション**のイベント。
  一部は終盤の特殊な進行状態に到達しないと表示されません。
- **判事 (ジャッジ) 関連**の追加シナリオ。
- 追加された**派遣ミッションの帰還報告文**。報告文は8種類の分岐があり、
  一部は特定のユニット構成でしか表示されません。
- 追加ミッションのひとつの**戦闘開始以降**。酒場での提示・詳細表示・受注までは
  ゲーム本来の進行で確認済みです。
- 追加クエスト用アイテムの**説明文**の実画面 (クリア後にしか手に入らないため)。
  表示名は確認済みです。

追加ミッションの一部は、酒場に出る条件が特殊です。
本プロジェクトの改変で到達できなくなったものは**ありません**
(条件はUS版の製品ROMがもともと持っているものです)。

いずれも不具合が確認されたわけではありません。**未確認**という記録です。

**協力のお願い:** 終盤までプレイされる方、特に次に当てはまる方の報告を歓迎します。

- 見慣れない名前のミッションが酒場に出現した
- 判事 (ジャッジ) 関連の見たことのないイベントが発生した
- 派遣ミッションの帰還報告が見慣れない文面だった
- 表示が英語のまま / 文字化け / レイアウトが崩れている箇所を見つけた

スクリーンショットと、そこに至るまでの進行状況を添えて
[Issue](../../../issues/new/choose) をお願いします。

## 3. 仕様 — 英語のまま残る箇所 (不具合ではありません)

以下は**日本版でも英語**です。日本語化されていないのではなく、
**日本版の見た目に合わせた結果**です。

- ウィンドウのタイトルバー
  (`MISSION` / `SYSTEM` / `OPTIONS` / `LIST` / `ACTION` /
  `ABILITIES` / `RESULTS` など)
- ミッションパネルの `RANK n` / `PAGE n/n`
- アビリティ画面の `Action` / `Reaction` / `Support` ラベルと
  A/R/S/C のカテゴリアイコン
- 一部の記号・単位表記

これらは画像として描かれており、日本版ROMの同じ画像も英語です
(日本版は `MISSION` が `QUEST` である等の語の違いはあります)。

**報告不要**ですが、判断に迷った場合は報告して構いません。

---

## 4. 対象外 — US版そのものの挙動

本プロジェクトは**US版をベース**にしています。
US版と日本版でゲーム内容が異なる部分 (バランス調整、追加ミッション、
US版で修正されたバグなど) は、**そのままUS版の挙動**になります。

これらは日本語化の不具合ではありません。
報告いただく場合は `upstream-us-behavior` として扱います。

---

## 5. 訳語の方針について

`Advanced Law` は **`アドバンスト・ロウ`** としています。

日本版ROMの物語本文中で同一の概念が複数回、一貫して
`アドバンスト・ロウ` と表記されているため、作品内の既存表記を優先しました。
