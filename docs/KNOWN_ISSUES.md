## 1. 表示 — ミッション条件文の重複表示 (未確定)

**症状**
特定のミッションを受注した後、条件文が

```
このクエストは、ゾディアック鉱石とゾディアック鉱石が必要だ。
```

のように、**同じアイテム名が2回**表示される場合があります。

**深刻度** 低 (表示のみ。進行に影響する報告はありません)

**状況**
**まだ不具合と確定していません。** どのレコードが描画されているかを
特定できていない段階です。US版本来の挙動である可能性も残っています。

**この現象を見かけた方へ:** 再現条件が分かると非常に助かります。
ミッション名 / 受注直後かどうか / 表示された文全体を添えて
報告してください。

## 2. 検証中 — 終盤・特殊なUS版追加シナリオ

**症状** (想定)
特になし。現時点で不具合は確認されていません。

**状況**
US版にのみ存在する追加シナリオのうち、一部は**終盤の特殊な進行状態**に
到達しないと表示されません。これらは日本語化そのものは完了していますが、
**実際にゲーム内で描画される場面を確認する作業が継続中**です。

つまり「翻訳が入っていない」のではなく、
「入っている翻訳を実機で見た記録がまだ取れていない」状態です。

対象は主に次のあたりです。

- US版で追加された終盤ミッションのイベント
- 判事 (ジャッジ) 関連の追加シナリオ
- 特定の派遣ミッションの帰還報告文
  (報告文は8種類の分岐があり、そのうち一部は特定の
  ユニット構成でしか表示されません)

**終盤までプレイされる方へ:** このあたりのスクリーンショットは
とても価値があります。文字化け・英語の残り・レイアウト崩れを
見かけたらぜひ報告してください。

詳細は [`US_ADDED_CONTENT.md`](US_ADDED_CONTENT.md) を参照してください。

## 4. 仕様 — 英語のまま残る箇所 (不具合ではありません)

以下は**日本版でも英語**です。日本語化されていないのではなく、
**日本版の見た目に合わせた結果**です。

- ウィンドウのタイトルバー
  (`MISSION` / `SYSTEM` / `OPTIONS` / `LIST` / `ACTION` /
  `ABILITIES` / `RESULTS` など)
- ミッションパネルの `RANK n` / `PAGE n/n`
- アビリティ画面の `Action` / `Reaction` / `Support` ラベルと
  A/R/S/C のカテゴリアイコン
- 一部の記号・単位表記

これらは画像として描かれており、日本版ROMの同じ画像も英語です
(日本版は `MISSION` が `QUEST` である等の語の違いはあります)。

**報告不要**ですが、判断に迷った場合は報告して構いません。

---

## 5. 対象外 — US版そのものの挙動

本プロジェクトは**US版をベース**にしています。
US版と日本版でゲーム内容が異なる部分 (バランス調整、追加ミッション、
US版で修正されたバグなど) は、**そのままUS版の挙動**になります。

これらは日本語化の不具合ではありません。
報告いただく場合は `upstream-us-behavior` として扱います。

---

## 6. 訳語の方針について

`Advanced Law` は **`アドバンスト・ロウ`** としています。

日本版ROMの物語本文中で同一の概念が複数回、一貫して
`アドバンスト・ロウ` と表記されているため、作品内の既存表記を優先しました。
この判断は Public Beta 2 でも維持しています。
