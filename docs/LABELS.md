# 推奨ラベル

GitHub の Issue / PR ラベルの案です。

**このリポジトリではまだラベルを作成していません。**
公開時に、必要になったものから作ってください。
最初から全部作る必要はありません。

---

## 最小構成 (公開時に作るもの)

| ラベル | 色 | 用途 |
|---|---|---|
| `bug` | `#d73a4a` | 不具合全般 |
| `text` | `#0e8a16` | 誤字・誤訳・表現の問題 |
| `ui-layout` | `#fbca04` | 文字のはみ出し、重なり、レイアウト崩れ |
| `crash` | `#b60205` | クラッシュ・ハング・画面破壊 |
| `build` | `#5319e7` | ビルドできない、ROMが認識されない |
| `needs-reproduction` | `#d4c5f9` | 再現手順の確認待ち |
| `confirmed` | `#0052cc` | 再現を確認済み |
| `known-issue` | `#c5def5` | `docs/KNOWN_ISSUES.md` に記載済み |
| `upstream-us-behavior` | `#bfd4f2` | US版そのものの挙動。日本語化の問題ではない |

## 必要になったら追加するもの

| `gameplay` | 進行・挙動の問題 |
| `hardware` | 実機 (フラッシュカート) 固有 |
| `emulator` | 特定エミュレータ固有 |

| `fixed` | 次のリリースで修正済み |
| `wontfix` | 対応しない (理由を必ずコメントすること) |
| `duplicate` | 重複 |

## 運用の指針

- **ラベルを増やしすぎないでください。** 使われないラベルは
  分類の役に立たず、報告する側を戸惑わせるだけです。
- Issue テンプレートは `bug` + `needs-reproduction`、
  および `build` を自動付与します。
  それ以外は手動で付けてください。
- `needs-reproduction` は、再現を確認できた時点で
  `confirmed` に置き換えてください。
- `upstream-us-behavior` は**閉じる前に必ず説明を書いてください。**
  報告者にとっては「直らないのはなぜか」が重要です。
- `known-issue` を付けた場合は、`docs/KNOWN_ISSUES.md` に
  該当項目があることを確認してください。無ければ追記してください。

## ROM関連のIssueへの対応

ROMの入手方法を尋ねる、共有を申し出る、ROMを添付する —
こうしたIssue・コメントは、

1. 添付ファイルがあれば**削除**し、
2. [`CONTRIBUTING.md`](../CONTRIBUTING.md) を案内して、
3. **クローズ**してください。

ラベルは不要です。議論の対象にしないでください。
