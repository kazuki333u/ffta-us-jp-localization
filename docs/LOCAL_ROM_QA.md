# ROMが必要な検証について

このプロジェクトの検査は2種類に分かれています。

| 分類 | ROM | 実行場所 |
|---|---|---|
| **PUBLIC_CI** | 不要 | GitHub Actions + ローカル |
| **LOCAL_ROM_QA** | 必要 | **ローカルのみ** |

GitHub の実行環境にROMは存在せず、**置く設計にもしていません。**

---

## 1. PUBLIC_CI — ROM不要

プルリクエストごとに GitHub Actions が自動実行します。
手元でも同じものを実行できます。

```
python -m pip install -r requirements-dev.txt

python tools/public_audit.py        # 公開前監査
python -m pytest tests/public -q    # 公開テストスイート
```

検査内容:

- 禁止ファイル (ROM / セーブ / パッチ / アーカイブ / 画像 / バイナリ) の混入
- ローカルパス・個人情報・認証情報の漏洩
- マニフェストの構文と件数の整合
- 公式原文がそのまま保存されていないか
- ビルドチェーンの構文と import の閉包
- 上流由来ファイルの帰属表示
- ビルダーのハッシュゲートの挙動 (誤ったROMを弾くか)
- 必須文書の存在
- **Git履歴**に禁止ファイルや巨大blobが無いか

**CIのsecret / cache / artifact にROMを入れません。
CIからROMをダウンロードもしません。**

---

## 2. LOCAL_ROM_QA — ROMが必要

こちらは**あなたの手元でだけ**実行できます。

### 2.1 ビルドの再現性

```
python build.py --us FFTA_US.gba --jp FFTA_JP.gba --output out.gba
```

`build.py` が出力ROMのSHA-256を固定値と照合します。
一致しない限り出力ファイルは書かれません。

決定性を自分で確かめる:

```
python build.py --us FFTA_US.gba --jp FFTA_JP.gba -o a.gba --work-dir w1
python build.py --us FFTA_US.gba --jp FFTA_JP.gba -o b.gba --work-dir w2
```

`a.gba` と `b.gba` は**バイト単位で一致**します。

### 2.2 ROM連続バイト列の監査

```
python tools/public_audit.py --us FFTA_US.gba --jp FFTA_JP.gba
```

追跡ファイルがROMの32バイト連続一致を含まないことを検査します
([`PROVENANCE.md`](PROVENANCE.md) §4)。

**公開・リリースの前には必ずこの形で実行してください。**
ROMなしでは `rom-substring` が SKIP になります。

### 2.3 実際にプレイしての確認

自動検査では**代替できません。**

- 誤字・誤訳
- 文脈に合わない訳
- 終盤・US版追加コンテンツの表示
- 実機 (フラッシュカート) での動作
- エミュレータ間の差異

**ここがいちばん人手を必要としている部分です。**
[`CONTRIBUTING.md`](../CONTRIBUTING.md) を参照してください。

---

## 3. なぜ分けているのか

- **ROMを公開の場に置かないため。** これが第一の理由です。
- CIを誰でも fork して動かせるようにするため。
  ROMを持っていない人でも、コードの検査には参加できます。
- ROM由来の検査を「持っている人が手元でやる」ことに限定するため。

---

## 4. 実行時QAハーネスについて

開発側には、エミュレータを自動操作してUIを探索し、
メモリを構造的に検査するQAハーネスがあります
(クラッシュ、ハング、ヒープ破壊、文字のはみ出し、
描画されたレコードの同定など)。

**これは公開リポジトリには含めていません。**

理由:

- エミュレータ本体と、その自動操作環境に依存します
- セーブステート (到達済みのゲーム状態) が必要です。
  これらはROM由来データとプレイヤー入力名を含みます
- 開発機のローカルパスに依存しています

将来的に、環境依存とローカルパスを切り離せた部分から
公開する可能性はあります。

現時点では、**公開リポジトリの検査は上記 §1 と §2 の範囲**です。
