# Public Beta 2 (RC23-based) — リリースノート (draft)

**日本語化された Final Fantasy Tactics Advance (US版) の公開ベータです。**

これは **1.0 正式版ではありません。** 不具合報告を集めるための公開です。

---

## これは何か

US版 FFTA を日本語表示にする、非公式のファンプロジェクトです。

- 日本語のテキスト・フォント・グラフィックは、**あなた自身のJP版ROM**から
  ビルド時に取り出されます。
- US版にしか存在しない内容は、**本プロジェクトが新規に翻訳**しました。
- US版が持つ追加ミッション・システム改善・バグ修正は**そのまま維持**されます。

**ROMは配布していません。** 配布しているのはビルドスクリプトだけです。

---

## 入手とビルド

```
python -m pip install -r requirements.txt
python build.py --us FFTA_US.gba --jp FFTA_JP.gba --output FFTA_US_JP.gba
```

必要なもの:

| | SHA-256 |
|---|---|
| US版ROM (pristine) | `43FC8204C6DCEEE58828AEBC7AF0C72EB807E99F35AD641C8BB0A4FA8B6EDC19` |
| JP版ROM (pristine) | `B13DD536808EF5D0FD4494386A9499F6FEB8310835D3F867CD17CC340D82BF9A` |

生成されるROM:

| | 値 |
|---|---|
| SHA-256 | `6C78CDEE7914056CEBF6A39354A6A82C8DA132C2D6A0D88928B4B6A2CDB717E6` |
| CRC32 | `8262D569` |
| サイズ | 16,777,216 バイト |

手順の詳細は [`BUILD.md`](BUILD.md)。

## 動作するもの

- **本編を通してプレイできます。**
- 製品ROM全体を再解析した結果、**プレイヤーから見える英語の残存は0件**
  (14,363レコードを走査)。
- 日本語化されたテキストエントリ **12,598**
  - JP版からの移植: 11,166
  - US版のみの新規翻訳: 1,332
  - その他: 100
- グリフ描画の照合: **4,606 / 4,606** がJP版ROMと同一のビットマップ。
- **ジョブアイコン 44/44** が日本版ROM本来の日本語ラベル入り。
- **アイテム情報の「装備可能ジョブ」ページ 29分類 / 361レコード**が
  正しく描画されます。
- 自動探索QA: **26ルート / 3,130 UI状態 / 12,766 遷移**、
  クラッシュ0・ハング0・リブート0 (同系列の以前のビルドでの計測)。
- 固定回帰スイート: **84/84 フレームが画素単位で一致**。

対応済みの画面には、ワールドマップ、酒場のミッション一覧と詳細パネル、
戦闘UI、ステータス／装備／アビリティ／ジョブチェンジ、ショップ、
ロウ画面、セーブ／ロード、名前入力 (日本語キーボード)、
オプション等が含まれます。

このリリースの公開ビルドは、次のとおり検証しています。

| 項目 | 結果 |
|---|---|
| 入力 US ROM | `43FC8204C6DCEEE58828AEBC7AF0C72EB807E99F35AD641C8BB0A4FA8B6EDC19` |
| 入力 JP ROM | `B13DD536808EF5D0FD4494386A9499F6FEB8310835D3F867CD17CC340D82BF9A` |
| 出力サイズ | 16,777,216 バイト |
| 出力 SHA-256 | `6C78CDEE7914056CEBF6A39354A6A82C8DA132C2D6A0D88928B4B6A2CDB717E6` |
| 出力 CRC32 | `8262D569` |
| 開発側の正本ビルドとの差分 | **0 バイト** |
| 独立したビルド回数 | **4 回** (うち3回はリポジトリを別ディレクトリへ複製した状態から) |
| すべて一致 | **はい** |

誤った入力の拒否も確認しています。

| 入力 | 結果 |
|---|---|
| `--us` と `--jp` を入れ替え | 拒否 (入れ替えの指摘あり) |
| JP版を `--us` に指定 | 拒否 |
| US版を `--jp` に指定 | 拒否 |
| 日本語化済みROMを `--us` / `--jp` に指定 | 拒否 (どのビルドかを表示) |
| 1バイトだけ改変したUS版 | 拒否 |
| 途中で切れたファイル | 拒否 (サイズ判定) |
| 存在しないファイル | 拒否 |

いずれの場合も**出力ファイルは書き込まれません**。

## 既知の問題

必ず [`KNOWN_ISSUES.md`](KNOWN_ISSUES.md) をお読みください。要点:

1. **ミッション条件文の重複表示 (未確定)** — 同じアイテム名が2回
   表示される場合があります。まだ不具合と確定していません。
2. **終盤・特殊なUS版追加シナリオの検証が継続中** — 日本語化は完了して
   いますが、実際に表示される場面の確認が終わっていません。
3. **特定の追加ミッションの戦闘以降が未確認** — 受注までは確認済みです。
4. **ウィンドウのタイトルバー等は英語のまま** — 日本版でも英語です。
   `Action` / `Reaction` / `Support` と A/R/S/C アイコンも同様です。
   不具合ではありません。

## 検証していないこと

正直に書きます。

- **通しプレイの網羅的な人力テストは行っていません。**
  自動探索と静的検査が主体です。
- **終盤コンテンツの実機確認は部分的です。**
- **実機 (フラッシュカート) での動作確認は限定的です。**
- **すべてのエミュレータで確認したわけではありません。**

だからこそ公開ベータです。**あなたのプレイが検証そのものです。**

## バージョンについて

| 呼称 | 意味 |
|---|---|
| **Public Beta 2 (RC23-based)** | 公開向けの呼称 |
| `v0.2.0-beta.2` | Git タグを付ける場合の形式 |

終盤コンテンツの検証が完了すること**です。
