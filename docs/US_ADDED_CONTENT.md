# US版追加コンテンツについて — 技術ノート

US版 FFTA には、日本版に存在しないコンテンツが含まれています。
本プロジェクトはそれらを**すべて日本語化しています**。

一方で、その一部については「本当にゲーム中で表示されるのか」を
確認しきれていません。このページはその状況を正確に記録するためのものです。

**「日本語化から漏れている」わけでも、「本プロジェクトが到達不能にした」
わけでもありません。**

---

## 1. US版が追加しているもの

日本版の対応レコードが空欄、または開発用のプレースホルダ
(`クエスト377`、`ダミー377`、`予備2` のような仮の文字列) である一方、
US版には実際の内容が入っている、という箇所があります。

もうひとつ、**日本版の同じ番号のスロットに「別のもの」が入っている**
という形もあります。この場合、日本版のレコードは仮の文字列ではなく
本物の日本語なので、上の「プレースホルダかどうか」という判定では
見つかりません (§1.1)。

主なものは次のとおりです。

| 内容 | 件数 |
|---|---|
| 追加ミッション名 | 20 |
| 追加ミッションの説明文 | 20 |
| 追加ユニット種別とその説明 | 2 |
| 追加シナリオ・イベント台詞 | 多数 |
| 追加された派遣ミッションの帰還報告文 | 40 |
| 追加クエストアイテムの名前と説明 | 2 |

これらは日本版に対応する日本語が存在しないため、
**本プロジェクトが新規に翻訳**しました。

このうち上表の 42 件は、初期のビルドでは日本版の**プレースホルダ文字列が
そのまま表示されていました** (`クエスト377` 等)。
これは Public Beta 1 のベースである RC17 で**修正済み**です。

### 1.1 日本版の同じスロットに別のものが入っている場合

US版のクエストアイテム `Stuffed Bear` (クリア後の追加ミッション
「ミュートの記憶」で必要になるアイテム) は、日本版に存在しません。
日本版の同じ番号のスロットには**まったく別のアイテム**が入っており、
そのアイテムを要求するクエストは日本版に1件もありません。

Public Beta 2 までのビルドでは、この別アイテムの名前と説明が
そのまま表示されていました。**Public Beta 3 で修正済み**です。
日本版に対応する名前が無いため、表示名
**「クマのぬいぐるみ」**と説明文は**本プロジェクトによる翻訳**であり、
日本版からの移植ではありません (説明のステータス行だけは
日本版のものをそのまま引き継いでいます)。

この形の見落としが他に無いことを確かめるため、クエストアイテム
**127スロットすべて**について「そのアイテムをどのクエストが要求するか」を
US版・日本版のミッションテーブルで突き合わせる監査を行っています
(`src/localizer/chain/ffta_us_added_item_identity_audit.py`)。
US版だけが要求するアイテムは**この1件のみ**で、残りはすべて
両版で同じクエストが同一のエントリを通して要求する同一アイテムでした。

## 2. 到達に特殊な条件が要る部分

追加コンテンツの一部は、通常の進行とは別の条件で表示されます。

具体的には、追加ミッションのひとつが酒場に出現する条件が
**ストーリーフラグ 0x036** ひとつだけになっており、
そこから先の追加コンテンツ群が連鎖しています。

### 現在の解析結果

製品版ROMのスクリプトとコードを走査した範囲では:

- フラグ 0x036 を **恒久的に 1 にする処理は確認できていません。**
- 1 を書く箇所は存在しますが、いずれも**同じ処理の中で数命令後に
  元へ戻される一時的な切り替え**でした。
- 全シーンスクリプトを走査しても、恒久的に立てる箇所は見つかっていません。

さらに、関連する別の追加ミッションが要求するアイテムは、
日本版由来のあるミッションからしか入手できず、
そのミッション自身の出現条件が **フラグ 0x036 が 0 であること** です。

### ここで断定しないこと

上記は**現時点の解析結果**であり、次のことは**主張しません**。

- 「通常プレイでは絶対に到達できない」
- 「開発側が意図的に没にしたデータである」
- 「US版の不具合である」

見落としの可能性、通信機能・特殊な入力・未解析の経路など、
確認できていない要素が残っています。
**分かっていること以上のことは書かない**方針です。

### 分かっていること

- 該当コンテンツの**日本語化は完了しています**。
- 本プロジェクトの改変によって到達不能になったものは**ありません**。
  条件はUS版の製品ROMがもともと持っているものです。
- 検証は、当該状態をゲーム自身のセーブ処理を通して構築したうえで
  **継続中**です。

**心当たりのある方へ:** 通常プレイ中にこれらの追加ミッションが
酒場に出現した経験がある方は、ぜひ報告してください。
上記の解析を覆す非常に重要な情報になります。

## 3. 検証の進み具合

US版のみのコンテンツを「シナリオ単位」で数えると、
**44グループ / 1,474レコード**です。

各グループについて、次の状態を記録しています。

| 状態 | 意味 |
|---|---|
| 検証済み | ゲーム本来の進行で、該当レコードが読まれたことを確認 |
| 部分検証 | 一部のレコードのみ確認済み |
| 未検証 | 表示される状態にまだ到達していない |

**未修正の不具合 (DEFECT_OPEN) は現在 0 件です。**

未検証のグループは「不具合が見つかった」のではなく、
「まだ確認できていない」という記録です。

### 実際に確認できたこと (Public Beta 3 時点)

- 追加ミッションのひとつは、ゲーム自身の進行によって
  イベント発生 → クリア判定 → 別の追加ミッションが酒場に出現、
  という流れを最後まで確認しました。
- そのミッションの**提示・詳細パネル・受注**まで、
  ゲーム本来のUIで日本語表示を確認しました。
- 追加された派遣ミッションの帰還報告文は、報告文が8種類の分岐を持ち、
  そのうち一部は**特定のユニット構成でしか表示されない**ことを確認しました。
  初期クランの構成では該当しないため、未確認のまま残っています。
- 追加クエストアイテムの**表示名**は、酒場のクエスト詳細パネル
  (「必要アイテム」の行) で日本語表示を確認しました。
  一方、**説明文**はそのアイテムを所持している状態の
  「アイテム → クエストアイテム」画面でしか描かれず、
  このアイテムはクリア後にしか手に入らないため、
  実画面での確認は**未了**です (レコード自体は静的に検証済み)。

## 4. 協力のお願い

終盤までプレイされる方、特に次に該当する方の報告を歓迎します。

- 見慣れない名前のミッションが酒場に出現した
- 判事 (ジャッジ) 関連の見たことのないイベントが発生した
- 派遣ミッションの帰還報告が見慣れない文面だった
- 表示が英語のまま / 文字化け / レイアウトが崩れている箇所を見つけた

スクリーンショットと、そこに至るまでの進行状況を添えて
[Issue](../../../issues/new/choose) をお願いします。

**ROMファイルは添付しないでください。**
