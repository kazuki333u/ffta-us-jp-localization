FFTA 日本語化ビルダー（Windows 版）
====================================

Final Fantasy Tactics Advance の US版ROMを、あなたのJP版ROMの日本語で
日本語化するツールです。非公式のファンプロジェクトです。

このフォルダにROMは入っていません。ツールがROMをダウンロードすることもありません。
日本語の文章・フォント・画像は、作るときにあなたのJP版ROMから読み出します。


■ 用意するもの

  ・あなたが持っている US版 のROM（.gba）
  ・あなたが持っている JP版 のROM（.gba）
  Python やコマンドの知識は要りません。


■ 使い方

  1. zip を右クリック →「すべて展開」で、好きな場所に展開します。
     （zip の中から直接起動しないでください）
  2. 展開したフォルダの FFTA_JP_Builder.exe をダブルクリックします。
  3. 「US版 ROM」と「JP版 ROM」の「選ぶ…」で、それぞれのROMを選びます。
     2本のROMを FFTA_JP_Builder.exe の上にまとめてドラッグしても選べます。
     どちらがUS版かJP版かはツールが自動で見分けます。
  4. 両方に「OK: …（対応する版です）」と出たら「日本語化ROMを作る」を押します。
  5. 数分で完成します。保存先（最初はUS版ROMと同じフォルダの FFTA_US_JP.gba）に
     日本語化されたROMができます。


■「WindowsによってPCが保護されました」と出たとき

  このツールには有料のコード署名がないため、初回に青い画面が出ることがあります。
  「詳細情報」を押すと「実行」ボタンが出ます。
  心配な場合は、配布ページに載っている zip の SHA-256 と、
  手元の zip のハッシュが一致するか確かめてください。
  （PowerShell で Get-FileHash .\FFTA_JP_Builder_windows.zip）


■「NG: 対応していないファイルです」と出たとき

  このツールが使えるROMは、US版・JP版ともに決まった1種類だけです。
  版の違い、先頭に余分なヘッダが付いたもの、すでに改変されたもの（日本語化済みを含む）
  は使えません。詳しくは配布ページの docs/TROUBLESHOOTING.md を見てください。


■ 作れなかったとき

  保存先には何も書かれません。ウィンドウ下の欄に理由が出ます。
  報告するときはその文だけを貼ってください。
  ROMファイルや作業フォルダ（ROMの写しが入っています）は添付しないでください。
