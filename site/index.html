FFTA 日本語化（北米版・US版ベース）

ファイナルファンタジータクティクスアドバンスの北米版（US版・英語版）を、US版の追加ミッションを残したまま日本語で遊ぶための、非公式のファンプロジェクトです。

Windows 版をダウンロード GitHub のリポジトリ

ROMもパッチも配布しません。ROMの入手先の案内もしません。日本語の文章・フォント・画像は、ビルドのときにあなた自身の日本版ROMから読み出します。

どんなものか

  • 海外版（北米版）の FFTA は、日本版に無い追加ミッション・システムの改善・バグ修正を持っています。
  • このビルダーは、北米版の中身はそのままに、表示を日本版の日本語に置き換えた ROM をあなたの PC の中で作ります。
  • 日本版に無い北米版だけの文章は、このプロジェクトが新しく日本語に訳しています。
  • 現在は公開ベータです。本編を通してプレイできる状態ですが、正式版ではありません。既知の問題は KNOWN_ISSUES にあります。

使い方（Windows）

  1. Releases から FFTA_JP_Builder_windows.zip をダウンロードして展開します。
  2. FFTA_JP_Builder.exe を起動し、北米版と日本版の ROM を選びます。
  3. 両方に「OK」と出たら「日本語化ROMを作る」を押します。

Python とコマンドで作る方法（Windows / macOS / Linux）は BUILD.md にあります。

対応する ROM

次の2本だけに対応します。SHA-256 の完全一致で判定し、違うファイルでは何も書き出しません。

よくある質問

FFTA の北米版（英語版）を日本語で遊べますか？

はい。あなた自身の北米版 ROM と日本版 ROM から、北米版の内容を日本語で表示する ROM を手元で作れます。

日本語化パッチは配布していますか？

いいえ。パッチも ROM も配布しません。配っているのは、2本の ROM から日本語化 ROM を作るプログラムだけです。

北米版だけの追加ミッションはどうなりますか？

そのまま残ります。日本版に無い文章は、このプロジェクトが新しく訳しています。

エミュレータは要りますか？

ビルドには要りません。出来上がった ROM を遊ぶときに、お使いの環境が必要です。

不具合を見つけたら？

Issues から報告してください。ROM ファイルは添付しないでください。
